# Models of MultiPie 3.1.3

Models created with MultiPie 3.1.3 (combined SAMB numbered in the order before 3.2.0) from `*_in.py`, and controls with the weights of their SAMB, for the conversion (renumbering) by `mp_convert` (`tests/test_convert_v3.py`).

- `graphene`: graphene (SG 191), C pz, bonds up to the second neighbor, all the types and irreps.
- `cubic_pd`: p and d orbitals at the origin of Pm-3m, spinful, all the types and irreps (electric/magnetic and s, k, l reordered).
