# Group information

The tables of all supported groups are generated by [MultiPieGen][multipiegen-group-info], together with the group database used by `Group`. They are provided as PDF files for

- **Overall information**: lists of all groups, compatibility relations, and active multipoles.
- **Point groups**: harmonics, character tables, symmetry operations, Wyckoff sites and bonds, representation matrices, multipolar harmonics, and atomic multipoles.
- **Space groups**: symmetry operations, Wyckoff sites and bonds.
- **Magnetic point groups**: symmetry operations, Wyckoff sites, and response tensors.
- **Magnetic space groups**: symmetry operations and Wyckoff sites.

See [Group Information in MultiPieGen][multipiegen-group-info].
