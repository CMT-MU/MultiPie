# Changes from Ver.2

MultiPie Ver.3 uses a new group database generated by MultiPieGen. The groups themselves (symmetry operations,
Wyckoff positions, characters) are unchanged, but the multipole data, i.e., the harmonics and the SAMB built on them,
are made in a new way. This page summarizes what changes for the users of Ver.2. A Japanese version is
[here](changes_ja.md).

**In short:**

- Create your models again with Ver.3. A model (`.pkl`) created with Ver.2 is refused.
- The SAMB $Z_j$ of a model span the same space as in Ver.2, but their numbering, signs, and values can differ. Assign
  the weights $z_j$ again, e.g., by fitting.
- Four f orbitals are renamed: `f2`, `f1`, `f3x`, `f3y` are now `fc`, `fs`, `fx`, `fy`.
- The irreps of some groups, e.g., D$_{\rm 3h}$, are in another order.
- Some functions of `Group` are removed or changed (see [Group](#changes-group)).

## Group database

- The database (`multipie/binary_data`) is generated by MultiPieGen, a separate project, and copied into MultiPie by
  `tools/sync_binary_data.py`; `multipie/binary_data/SOURCE.txt` records the commit of MultiPieGen it comes from. The
  tools that created the database in Ver.2 (`others/tools`) are removed.
- The database is about 20 MB (81 MB in Ver.2). The optional data of the point groups (`PG/*_opt.pkl`) are merged
  into the data of each point group. The file names have `_` instead of the `:` of the group ids, e.g., `PG/PG_32.pkl`
  for `PG:32` (`PG/PG:32.pkl` in Ver.2), so that MultiPie can be installed from git also on Windows.
- The tables of the groups (PDF) are also generated by MultiPieGen. [Group Information](group_doc.md) links to them;
  the group pages of the Ver.2 documentation are removed.

## Conventions

**Irrep order.** The irreps follow the order of the character table, with `g` before `u` and the irreps with `'` before
those with `''`. The order changes for C$_{\rm 3h}$, D$_{\rm 3h}$ and their other settings, e.g., D$_{\rm 3h}$:

| Ver.2 | Ver.3 |
|:--|:--|
| $A_1', A_2', A_1'', A_2'', E', E''$ | $A_1', A_2', E', A_1'', A_2'', E''$ |

The first irrep is still the identity irrep.

**Orbital names.** The orbitals are renamed as follows. The old names are not accepted in a model input; an error tells
the new name.

| Ver.2 | Ver.3 | function | Wannier90 |
|:--|:--|:--|:--|
| `f2` | `fc` | $\frac{\sqrt{10}}{4}x(x^2-3y^2)$ | `fx(x2-3y2)` |
| `f1` | `fs` | $\frac{\sqrt{10}}{4}y(3x^2-y^2)$ | `fy(3x2-y2)` |
| `f3x` | `fx` | $\frac{\sqrt{6}}{4}x(4z^2-x^2-y^2)$ | `fxz2` |
| `f3y` | `fy` | $\frac{\sqrt{6}}{4}y(4z^2-x^2-y^2)$ | `fyz2` |

The orbitals of rank 4, which appear in the names of multipoles (e.g., the active multipoles of the response tensors),
are also renamed: `ga`, `gb`, `gc` are now `gc`, `gs`, `gc4` (note that `gc` now means the old `ga`).

**Multiplicity.** The multiplicity `n` of a key is always that of the point-group harmonics `(X, l, Gamma)`, which fixes
its xyz polynomial; entries sharing all the other fields are numbered by `p`. See the
[User Guide](guide.md).

## Harmonics

- The value of `Group.harmonics` is `(expression, U)`; the third item of Ver.2 (the expression in terms of the
  tesseral harmonics) is removed.
- The expressions are expanded polynomials, e.g., $\frac{3\sqrt{10}}{4}x^2y - \frac{\sqrt{10}}{4}y^3$ instead of
  $\frac{\sqrt{10}}{4}y(3x^2 - y^2)$.
- The keys are the same for all 47 point groups. 32 harmonics change sign, the rank-4 $E$ harmonics with multiplicity 2
  or 3 of the 16 trigonal and hexagonal point groups (from $E_{2g}$ of D$_{\rm 6h}$); the expression and $U$ change sign
  together.
- The multipolar harmonics (`Group.multipolar_harmonics`) are given up to rank 3 (rank 11 in Ver.2), with internal
  bases of cubic or hexagonal orbitals and symbols such as $Q_{x}$.

## Atomic SAMB

- The same keys and matrices as in Ver.2, except for sign changes in the D$_{\rm 6h}$ family (from the harmonics).
- The complex point groups (`-c`) also have atomic SAMB.

## Cluster SAMB

- The site and bond cluster SAMB of each irrep span the same space as in Ver.2, but the values differ, as they are made
  from another representative point: e.g., about 69% of the site cluster SAMB are unchanged, 14% change sign, and 17%
  change their values.
- The bond cluster SAMB are given as one set, `Group.cluster_samb(wp, "bond")`: the symmetric (`Q`, `G`, real) and the
  anti-symmetric (`T`, `M`, pure imaginary) bond functions together. The types `"bond_s"`, `"bond_a"` and `"vector"`
  are removed.
- The keys of the anti-symmetric bond functions can differ from Ver.2 in `p`, in `n`, or in `(X, l, Gamma)`, e.g., the
  `p` of the key is kept from the top group, giving symbols such as $\mathbb{T}_{1}^{(b)}(E_{1u},a)$.
- The complex point groups have no cluster SAMB (as in Ver.2); `Group.cluster_samb` raises an error for them.

## Combined SAMB and models

- The combined SAMB of a model span the same space of matrices as in Ver.2, with the same number of SAMB, but the
  numbering $z_j$, the signs, and the values can differ. The band structure of a model with given weights is therefore
  different unless the weights are converted.
- `MaterialModel.load` (and so `mp_analyze`) refuses a model created by Ver.2 with an error. Create the model again with
  `mp_create`, and assign the weights again.
- The bands of a model obey the symmetry in the same way; see [Checks by symmetry](materials.md) for the tests that
  hold across the versions.

## Group

| Ver.2 | Ver.3 |
|:--|:--|
| `Group(tag, with_opt=True)`, `Group.opt` | removed |
| `Group.opt["representation_matrix"]` | `Group.representation_matrix` |
| `Group.opt["harmonics_multipole"]` | `Group.multipolar_harmonics` (rank <= 3) |
| `Group.opt["harmonics_irrep"]` | removed (use the keys of `Group.harmonics`) |
| `Group.harmonics` value `(expression, U, tesseral expression)` | `(expression, U)` |
| `Group.cluster_samb(wp, "bond_s" / "bond_a" / "vector")` | removed; `Group.cluster_samb(wp, "bond")` |
| `Group.response_tensor_all(X)` computes the tensors | reads them from the database (the same tensors) |
| `wyckoff[...]["reference"]` | other values (another representative point) |
| `symmetry_operation["mapping"]` of a PG, right cosets | left cosets along the parent groups; also given for SG |
| no bonds for the complex PGs | Wyckoff bonds for the complex PGs |
| - | `wyckoff["bond"][...]["symmetry"]` (site symmetry of the bond center) |

The symmetry operations (and their order), the Wyckoff labels, positions and mappings, the character tables (except
the order of the irreps), and the data of MPG and MSG are unchanged.

## Response tensors

- The response tensors are the same as in Ver.2, except for the names of the multipoles, and the sign of `gv`.
- The names of the active multipoles follow the renamed orbitals, e.g., `Qf1` is now `Qfs`. Their aliases
  (`convert_mp_alias`) are made from the LaTeX names in the database, e.g., `Qfc` is $\mathbb{Q}_{3c}$.
- `multipole_rank(tag)` gives the rank of an active multipole from its name.

## Related packages

- QtDraw up to 3.3.1 works with MultiPie 2.5 or later in Ver.2, not with Ver.3; QtDraw 3.3.1 requires
  `multipie~=2.5`. A version of QtDraw for Ver.3 is planned.
