# User Guide

A guide to the quantities provided by MultiPie and how to read and use them, in English (en) and Japanese (ja).

- **User Guide** [[en](guide/users_guide.md), [ja](guide/users_guide_ja.md)]: the multipole key (`PGMultipoleType`)
  and its symbol, point-group harmonics, atomic orbitals, atomic SAMB, cluster SAMB (site, bond), combined SAMB and the
  tight-binding model, response tensors, and multipolar harmonics, with code examples.
- **Changes from Ver.2** [[en](changes.md), [ja](changes_ja.md)]: what changes with the new group database of Ver.3.
- **Examples of materials** [[en](materials.md)]: tight-binding models of SrVO$_3$, MoS$_2$, and Te.
