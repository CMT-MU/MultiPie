# User Guide

This guide explains the quantities that MultiPie provides and how to read and use them: the multipole key and its
symbol, the point-group harmonics, the atomic orbitals, the atomic, cluster, and combined SAMB (symmetry-adapted
multipole basis), the tight-binding model built from them, and the response tensors. A Japanese version is
[here](guide/users_guide_ja.md).

The group data come from the group database generated by MultiPieGen; the tables of all groups are in
[Group Information](https://cmt-mu.github.io/MultiPieGen/src/group_info.html). The code examples use `Group` (the group data) and `MaterialModel` (a model):

```python
from multipie import Group, MaterialModel
```

(multipole-key)=
## 1. Multipole key

Every multipole of a point group (harmonics, atomic SAMB, cluster SAMB, combined SAMB) is labeled by the named tuple
`PGMultipoleType(X, l, Gamma, n, p, s, k, x)` of the `multipie` package. Its value holds all the components of the
multiplet, in the order of the components of the irrep.

| field | meaning | values |
|:--|:--|:--|
| `X` | type, by the parity under the spatial inversion ($\mathcal{P}$) and the time reversal ($\mathcal{T}$) | `Q` electric ($\mathcal{P} = (-1)^l$, $\mathcal{T}$ even), `G` electric toroidal ($(-1)^{l+1}$, even), `T` magnetic toroidal ($(-1)^l$, odd), `M` magnetic ($(-1)^{l+1}$, odd) |
| `l` | rank | 0, 1, 2, ... |
| `Gamma` | irrep of the point group | name in the character table, e.g., `A1g`, `Eu`, `T2g` |
| `n` | multiplicity of the harmonics `(X, l, Gamma)`: which of the harmonics with the same `(X, l, Gamma)` | 1, 2, ...; `-1` if unique |
| `p` | extra multiplicity, numbering the entries that share all the other fields | 1, 2, ...; `-1` if unique |
| `s` | internal rank (rank of the internal degree of freedom, e.g., the spin) | 0 (scalar), 1 |
| `k` | internal component: the orbital part has rank `l + k` | `-s, ..., s` |
| `x` | internal type | `q` (polar), `g` (axial) |

- `(X, l, Gamma, n)` always identifies a point-group harmonics (its xyz polynomial and $U$); `T` and `M` use the
  harmonics of `Q` and `G`.
- Scalar quantities (harmonics, cluster SAMB) have `s = 0, k = 0, x = "q"`.
- A key can be given as a plain tuple, e.g., `("Q", 1, "T1u", -1, -1, 0, 0, "q")`. The data are `Dict`, a dictionary
  with these keys, which can select and sort its entries by the fields, e.g., `harmonics.select(X="Q", l=2)`.

**Symbol.** A multipole is written with the LaTeX symbol made from its key,

$$
\mathbb{X}_{l,\gamma}^{(s,k;\,\mathrm{tag})}(\Gamma, n\,p),
$$

| part | from the key | written |
|:--|:--|:--|
| $\mathbb{X}$ | `X` | $\mathbb{Q}, \mathbb{G}, \mathbb{T}, \mathbb{M}$ |
| $l$ | `l` | always |
| $\gamma$ | component (1, 2, ...) | only for one component of a multiplet of an irrep with dimension > 1 |
| $(s, k)$ | `s`, `k` | only if `s > 0` |
| tag | kind of data | none for the harmonics; `a` atomic SAMB, `s` site cluster SAMB, `b` bond cluster SAMB, `c` combined SAMB |
| $\Gamma$ | `Gamma` | always, e.g., $T_{1u}$ |
| $n$ | `n` | only if `n != -1` |
| $p$ | `p` | only if `p != -1`, as a letter `1 -> a, 2 -> b, ...` |

`Group.tag_multipole(key, comp=None, latex=False, superscript="")` makes the symbol, with `superscript` the tag:

```python
>>> Group.tag_multipole(("Q", 1, "T1u", -1, -1, 0, 0, "q"), 0, latex=True)
'\\mathbb{Q}_{1,1}(T_{1u})'
```

| key | symbol | meaning |
|:--|:--|:--|
| `("Q", 1, "T1u", -1, -1, 0, 0, "q")` | $\mathbb{Q}_{1}(T_{1u})$ | electric dipole of O$_{\rm h}$, $(x, y, z)$ |
| `("M", 1, "T1g", -1, -1, 0, 0, "q")` | $\mathbb{M}_{1}^{(a)}(T_{1g})$ | atomic SAMB: orbital angular momentum |
| `("M", 1, "T1g", -1, -1, 1, -1, "q")` | $\mathbb{M}_{1}^{(1,-1;a)}(T_{1g})$ | atomic SAMB: spin magnetic dipole |
| `("T", 1, "Eu", -1, 1, 0, 0, "q")` | $\mathbb{T}_{1}^{(b)}(E_{u},a)$ | bond cluster SAMB of D$_{\rm 4h}$: imaginary hoppings with the symmetry of $(x, y)$ |
| `("Q", 0, "A1g", -1, 2, 0, 0, "q")` | $\mathbb{Q}_{0}^{(c)}(A_{1g},b)$ | the second ($p = 2$) combined SAMB of the same harmonics |

(point-group-harmonics)=
## 2. Point-group harmonics

**Spherical and tesseral harmonics.** The harmonics of rank $l$ are built from the homogeneous polynomials

$$
O_{lm}(\boldsymbol{r}) = \sqrt{\frac{4\pi}{2l+1}}\, r^l\, Y_{lm}(\theta, \phi), \qquad m = l, l-1, \dots, -l,
$$

e.g., $O_{10} = z$, $O_{1,\pm1} = \mp(x \pm iy)/\sqrt{2}$. Their real combinations are the tesseral harmonics, e.g.,
$C_{11} = x$, $S_{11} = y$, $C_{22} = \frac{\sqrt{3}}{2}(x^2 - y^2)$, $S_{22} = \sqrt{3}xy$.

**Point-group harmonics.** A harmonics `(X, l, Gamma, n)` of a point group is a set of rank-$l$ functions that forms a
basis of the irrep $\Gamma$. Its component $\gamma$ is

$$
X_{l\Gamma n}^{(\gamma)}(\boldsymbol{r}) = \sum_{m} U_{m\gamma}\, O_{lm}(\boldsymbol{r}),
$$

with the unitary matrix $U$ (`(2l+1) x dim`, rows $m = l, \dots, -l$). `Group.harmonics` gives, for each key, the
polynomials of the components and $U$:

```python
>>> g = Group("Oh")
>>> ex, U = g.harmonics[("Q", 1, "T1u", -1, -1, 0, 0, "q")]
>>> ex
array([x, y, z], dtype=object)
>>> U
array([[-sqrt(2)/2, sqrt(2)*I/2, 0],
       [0, 0, 1],
       [sqrt(2)/2, sqrt(2)*I/2, 0]], dtype=object)
```

- The harmonics are given up to rank 11, for `Q` (polar) and `G` (axial). An axial harmonics transforms with the extra
  factor $\det R$ under an improper operation $R$, so that `Q` and `G` of the same function can belong to different
  irreps, e.g., in C$_{\rm 4v}$, $\mathbb{Q}_{1}(A_{1}) = z$ but $\mathbb{G}_{1}(A_{2}) = z$. In a group of proper
  rotations only, `Q` and `G` are the same.
- When an irrep appears more than once at the same rank, `n = 1, 2, ...` distinguishes the harmonics, e.g., in
  C$_{\rm 4h}$, $\mathbb{Q}_{2}(B_{g},1) = \frac{\sqrt{3}}{2}(x^2 - y^2)$ and $\mathbb{Q}_{2}(B_{g},2) = \sqrt{3}xy$.
- The harmonics of a space group or a magnetic group are those of its point group.

(atomic-orbitals)=
## 3. Atomic orbitals

The orbitals of rank $L = 0, 1, 2, 3$ (s, p, d, f) are the basis of the atomic SAMB. Three bases are used, given by
`Group.atomic_basis(basis_type)`:

**`lg` (real orbitals, spinless).** The tesseral harmonics:

| $L$ | orbitals | functions |
|:--|:--|:--|
| 0 | `s` | $1$ |
| 1 | `px`, `py`, `pz` | $x$, $y$, $z$ |
| 2 | `dv`, `dxy`, `dxz`, `dyz`, `du` | $\frac{\sqrt{3}}{2}(x^2-y^2)$, $\sqrt{3}xy$, $\sqrt{3}xz$, $\sqrt{3}yz$, $z^2 - \frac{x^2+y^2}{2}$ |
| 3 | `fc`, `fs`, `fbz`, `f3`, `fx`, `fy`, `faz` | $\frac{\sqrt{10}}{4}x(x^2-3y^2)$, $\frac{\sqrt{10}}{4}y(3x^2-y^2)$, $\frac{\sqrt{15}}{2}z(x^2-y^2)$, $\sqrt{15}xyz$, $\frac{\sqrt{6}}{4}x(4z^2-x^2-y^2)$, $\frac{\sqrt{6}}{4}y(4z^2-x^2-y^2)$, $\frac{1}{2}z(2z^2-3x^2-3y^2)$ |

**`lgs` (real orbitals with spin).** `lg` times the spin `u` (up) and `d` (down), the spin fastest:
`(px,u), (px,d), (py,u), ...`.

**`jml` (total angular momentum).** $|J, M\rangle$ with $J = L \mp 1/2$, in the order of $J$ ascending and $M$
descending, e.g., for $L = 1$: `(1/2,1/2), (1/2,-1/2), (3/2,3/2), ..., (3/2,-3/2)`.

In a model input, the orbitals of a site are given by these names, e.g., `"d"` (all five), `["dyz", "dxz", "dxy"]`, or
`"(3/2,p)"` for `jml`. A spinful model (`"spinful": True`) uses `lgs` (or `jml`).

(atomic-samb)=
## 4. Atomic SAMB

The atomic SAMB are the matrices of the atomic multipole operators in the orbital basis, adapted to the point group.
They describe the on-site degrees of freedom of the electrons of an atom: the charge, the orbital (quadrupole) order,
the orbital angular momentum, the spin, and so on.

- The multipoles $X_{lm}^{(s)}(k)$ of `X = Q, G, T, M` with `s = 0` (orbital) and `s = 1` (spin-dependent),
  symmetry-adapted with $U$ of the harmonics, $X_{l\Gamma n}^{(s)}(k)[\gamma] = \sum_m U_{m\gamma} X_{lm}^{(s)}(k)$.
- Each component has the norm 1 in a diagonal block ($L_1 = L_2$), and $1/\sqrt{2}$ in an off-diagonal block.

`Group.atomic_samb(basis_type, (L1, L2))` gives, for each key, the matrices of the components, `(dim, n1, n2)`, and the
expression of the harmonics:

```python
>>> a = g.atomic_samb("lg", (1, 1))  # p-p block of Oh.
>>> list(a.keys())
[('Q', 0, 'A1g', -1, -1, 0, 0, 'q'), ('Q', 2, 'Eg', -1, -1, 0, 0, 'q'), ('Q', 2, 'T2g', -1, -1, 0, 0, 'q'), ('M', 1, 'T1g', -1, -1, 0, 0, 'q')]
>>> mat, ex = a[("M", 1, "T1g", -1, -1, 0, 0, "q")]
>>> mat[0]  # x component, l_x / sqrt(2) in (px, py, pz).
array([[0, 0, 0],
       [0, 0, -sqrt(2)*I/2],
       [0, sqrt(2)*I/2, 0]], dtype=object)
```

For the p orbitals of O$_{\rm h}$: $\mathbb{Q}_{0}^{(a)}(A_{1g})$ is the charge ($\propto$ identity),
$\mathbb{Q}_{2}^{(a)}(E_{g})$ and $\mathbb{Q}_{2}^{(a)}(T_{2g})$ the orbital quadrupoles, and
$\mathbb{M}_{1}^{(a)}(T_{1g})$ the orbital angular momentum. With the spin (`lgs`), the spin magnetic dipole is
$\mathbb{M}_{1}^{(1,-1;a)}(T_{1g})$, and the spin-orbit coupling $\boldsymbol{l} \cdot \boldsymbol{s}$ of the p orbitals
is proportional to $\mathbb{Q}_{0}^{(1,1;a)}(A_{1g})$.

(cluster-samb)=
## 5. Cluster SAMB

The cluster SAMB of a Wyckoff position are functions on its $N$ equivalent sites (or bonds) that form bases of the
irreps of the group. They describe how a quantity is distributed over the sites or the bonds of a cluster.

- **Site.** Functions on the $N$ sites of a site Wyckoff position (e.g., `2a`). They are real, of type `Q`, and form a
  complete orthonormal set.
- **Bond.** Functions on the $N$ bonds of a bond Wyckoff position. The label `2b@1o` is the bond Wyckoff position `2b`
  (2 bonds) whose centers are at the site Wyckoff position `1o`. The symmetric bond functions (the same value for the
  two directions of a bond, a real hopping) have the type `Q` or `G` and real values; the anti-symmetric ones (opposite
  signs for the two directions, an imaginary hopping) have the type `T` or `M` and pure imaginary values.

`Group.cluster_samb(wp)` and `Group.cluster_samb(wp, "bond")` give, for each key, the values on the sites or bonds,
`(dim, N)`, and the expression of the harmonics. For D$_{\rm 4h}$:

```python
>>> d = Group("D4h")
>>> d.find_wyckoff_site("[0,0,1/4]")[0]  # two sites at (0, 0, ±z).
'2a'
>>> for key, (samb, ex) in d.cluster_samb("2a").items(): print(key[:3], samb, ex)
('Q', 0, 'A1g') [[sqrt(2)/2 sqrt(2)/2]] [1]
('Q', 1, 'A2u') [[sqrt(2)/2 -sqrt(2)/2]] [z]
>>> for key, (samb, ex) in d.cluster_samb("2b@1o", "bond").items(): print(key[:5], samb.tolist())
('Q', 0, 'A1g', -1, -1) [[sqrt(2)/2, sqrt(2)/2]]
('Q', 2, 'B1g', -1, -1) [[-sqrt(2)/2, sqrt(2)/2]]
('T', 1, 'Eu', -1, 1) [[I, 0], [0, I]]
```

The bonds of `2b@1o` are along $x$ and $y$ through the origin: $\mathbb{Q}_{0}^{(b)}(A_{1g})$ is the uniform real
hopping, $\mathbb{Q}_{2}^{(b)}(B_{1g})$ the real hopping with opposite signs on the two bonds ($x^2 - y^2$ symmetry), and
$\mathbb{T}_{1}^{(b)}(E_{u},a)$ the imaginary hoppings with the symmetry of $(x, y)$, a current along each bond.

(combined-samb)=
## 6. Combined SAMB and the model

A tight-binding model is written by the combined SAMB, products of an atomic SAMB (on-site or bra-ket orbitals) and a
cluster SAMB (sites or bonds) combined into an irrep with the Clebsch-Gordan coefficients:

$$
Z_j = \sum_{\gamma_1 \gamma_2} C^{\gamma}_{\gamma_1 \gamma_2}\, X^{(\mathrm{a})}_{\gamma_1} \otimes Y^{(\mathrm{s/b})}_{\gamma_2},
\qquad H = \sum_j z_j Z_j.
$$

`MaterialModel.analyze(model_input)` (or `mp_create`) builds all of them for the sites, orbitals, and bonds of the
model. The SAMB of the identity irrep, of type `Q` and `G` (time-reversal even), are those allowed in a Hamiltonian;
`"SAMB_select": {"Gamma": "IR"}` selects them. For graphene (two C $p_z$ sites, bonds up to the second neighbor):

```python
>>> mm = MaterialModel()
>>> mm.analyze({"model": "graphene", "group": 191, "cell": {"c": 4}, "site": {"C": ("[1/3,2/3,0]", "pz")},
...             "bond": [("C", "C", [1, 2])], "SAMB_select": {"Gamma": "IR"}, "pdf": {"create": False}})
>>> for z, (symbol, u, key, comp) in mm["combined_id"].items(): print(z, symbol, u.samb_type.wyckoff, u.neighbor)
z1 \mathbb{Q}_{0}^{(c)}(A_{1g}) 2c 0
z2 \mathbb{Q}_{0}^{(c)}(A_{1g}) 3a@3f 1
z3 \mathbb{Q}_{0}^{(c)}(A_{1g}) 6b@6l 2
```

- `mm["combined_id"]` gives, for each $z_j$, its symbol, the site or bond cluster with its neighbor order
  (`u.samb_type` and `u.neighbor`), the key, and the component.
- `mm["combined_samb"]` gives the definition of each combined SAMB: for each atomic and cluster block, the list of
  `(coefficient, atomic key, atomic component, cluster key, cluster component)`.
- `mm.get_combined_samb_matrix(fmt="value")` gives the matrix of each $Z_j$ in real space, with the keys
  `(n1, n2, n3, m, n)`: the lattice vector $\boldsymbol{R} = (n_1, n_2, n_3)$ and the bra and ket indices of
  `mm["full_matrix"]["ket"]`. E.g., the nearest-neighbor hopping $Z_2$ of graphene has the elements $1/\sqrt{6}$ (6
  bonds, normalized).
- The PDF of the model (`mp_create` with `"pdf": {"create": True}`) lists all the SAMB with their definitions.

The weights $z_j$ are given in the control of `ModelAnalyzer` (or `mp_analyze`), `{"samb": {"parameter": {"z1": ...}}}`.
Since each $Z_j$ is normalized, $z_j$ has the unit of energy. The numbering of $z_j$ depends on the group database
(see [Changes from Ver.2](changes.md)); the space spanned by the SAMB does not. See
[Examples of materials](materials.md) for complete examples.

(response-tensors)=
## 7. Response tensors

A response tensor of rank 0 to 4 relates two physical quantities, e.g., a current and an electric field. For each of
the 157 magnetic point groups, `Group.response_tensor_all(X)` gives the tensors allowed by symmetry.

**Type.** The type `X` of a tensor is given by its parity under the spatial inversion and the time reversal. The four
types are usually called i-polar, i-axial, c-polar, and c-axial tensors, where i (c) means that the tensor is invariant
(changes sign) under the time reversal:

| name | `X` | spatial inversion | time reversal |
|:--|:--|:--|:--|
| i-polar tensor | `Q` | polar | even |
| i-axial tensor | `G` | axial | even |
| c-polar tensor | `T` | polar | odd |
| c-axial tensor | `M` | axial | odd |

A response is carried by the multipoles in its tensor (see **Active multipoles** below), for example:

| response | tensor `(X, rank, opt)` | multipoles |
|:--|:--|:--|
| electric conductivity (symmetric part) | `("Q", 2, "s")` | electric monopole, electric quadrupole |
| anomalous Hall effect | `("T", 2, "a")` | magnetic dipole (MD), e.g., $T_{xy} = \mathbb{M}_{z}$ |
| magneto-electric effect | `("M", 2, "s")`, `("M", 2, "a")` | magnetic monopole (MM) and magnetic quadrupole (MQ) in the symmetric part, magnetic toroidal dipole (MTD) in the anti-symmetric part |
| Edelstein (current-induced magnetization) effect | `("G", 2, "s")`, `("G", 2, "a")` | electric toroidal monopole (ETM) and electric toroidal quadrupole (ETQ) in the symmetric part, electric dipole (ED) in the anti-symmetric part |

**Part of the tensor (`opt`).** A tensor of rank 2 or higher is divided into parts by the symmetry of its indices:
`s` symmetric and `a` anti-symmetric in a pair of indices. The table below gives the relations for `X = Q` (the other
types have the same relations). The indices before `;` form the pair (or the triple) of the rows of the matrix, and
those after it the columns. The index sets are

- `c` = `[x, y, z]`,
- `v` = `[xx, yy, zz, yz, zx, xy]` (symmetric pairs),
- `a` = `[yz, zx, xy]` (anti-symmetric pairs),
- `u` = `[xx, yy, zz, yz, zx, xy, zy, xz, yx]` (all pairs),
- `t` = `[xxx, yyy, zzz, yyz, zzx, xxy, yzz, zxx, xyy, xyz]` (symmetric triples),

and "independent" is the number of independent components of the part without any symmetry.

| rank | `opt` | relation among the components | independent | matrix (rows x columns) |
|:--|:--|:--|:--|:--|
| 0 | `""` | - | 1 | 1 x 1 |
| 1 | `""` | - | 3 | 1 x 3 (`c`) |
| 2 | `s` | $X_{ab} = X_{ba}$ | 6 | 3 x 3 (`c` x `c`) |
| 2 | `a` | $X_{ab} = -X_{ba}$ | 3 | 3 x 3 (`c` x `c`) |
| 3 | `ss` | $X_{abc}$ fully symmetric in $a, b, c$ | 10 | 6 x 3 (`v` x `c`) |
| 3 | `sa` | $X_{ab;c} = X_{ba;c} = -(X_{ac;b} + X_{bc;a})$ | 8 | 6 x 3 (`v` x `c`) |
| 3 | `a` | $X_{ab;c} = -X_{ba;c}$ | 9 | 3 x 3 (`a` x `c`) |
| 4 | `sss` | $X_{ab;cd} = X_{ba;cd} = X_{ab;dc} = X_{cd;ab}$ | 21 | 6 x 6 (`v` x `v`) |
| 4 | `ssa` | $X_{ab;cd} = X_{ba;cd} = X_{ab;dc} = -X_{cd;ab}$ | 15 | 6 x 6 (`v` x `v`) |
| 4 | `aas` | $X_{ab;cd} = -X_{ba;cd} = -X_{ab;dc} = X_{cd;ab}$ | 6 | 3 x 3 (`a` x `a`) |
| 4 | `aaa` | $X_{ab;cd} = -X_{ba;cd} = -X_{ab;dc} = -X_{cd;ab}$ | 3 | 3 x 3 (`a` x `a`) |
| 4 | `sa` | $X_{ab;cd} = X_{ba;cd} = -X_{ab;dc}$ | 18 | 6 x 3 (`v` x `a`) |
| 4 | `as` | $X_{ab;cd} = -X_{ba;cd} = X_{ab;dc}$ | 18 | 3 x 6 (`a` x `v`) |
| 4 | `s` | $X_{ab;c;d} = X_{ba;c;d}$ (`sss` + `ssa` + `sa`) | 54 | 6 x 9 (`v` x `u`) |
| 4 | `a` | $X_{ab;c;d} = -X_{ba;c;d}$ (`aas` + `aaa` + `as`) | 27 | 3 x 9 (`a` x `u`) |
| 4 | `t` | $X_{abc;d}$ fully symmetric in $a, b, c$ | 30 | 10 x 3 (`t` x `c`) |

For example, the electric conductivity $\sigma_{ab}$ ($j_a = \sigma_{ab} E_b$) is a rank-2 tensor; its symmetric part
(`s`) is the ordinary conductivity, and its anti-symmetric part (`a`, odd under the time reversal) the anomalous Hall
conductivity, which is carried by the magnetic dipole. The magneto-electric tensor $\alpha_{ab}$
($P_a = \alpha_{ab} H_b$) is axial and odd under the time reversal (`M`): its symmetric part is carried by the
magnetic monopole and the magnetic quadrupoles, and its anti-symmetric part by the magnetic toroidal dipole. The
Edelstein (current-induced magnetization) tensor $\chi_{ab}$ ($M_a = \chi_{ab} j_b$) is axial and even under the time
reversal (`G`): its symmetric part is carried by the electric toroidal monopole and quadrupoles, as in a chiral crystal,
and its anti-symmetric part by the electric dipole, as in a polar crystal.

**Active multipoles.** Each tensor component is decomposed into multipoles (irreducible cartesian parts). Only the
active multipoles of the group, those invariant under all its operations including the time reversal, can be nonzero.
This gives the nonvanishing components and the relations among them. `Group.active_multipole` lists them, named by
`X` + an orbital name, e.g., `Qdu`; `multipole_rank` gives the rank and `convert_mp_alias` the alias of a name (both in
`multipie.util.util_response_tensor`), e.g., `Qdu` has the rank 2 and the alias `Qu`.

**Value.** For each key `(X, rank, opt)`, the value is the matrix of the components (symbols such as $Q_{xyz}$, and `0`
for the vanishing ones; rows and columns as in the table above), and a dict giving the expression of each nonzero
component in terms of the active multipoles.

```python
>>> m = Group("MPG:15.1.53")  # 4/mmm.
>>> m.active_multipole
['Qs', 'Qdu', 'Qg', 'Qgu', 'Ts', 'Tdu', 'Tg', 'Tgu']
>>> tensor, ex = m.response_tensor_all("Q")[("Q", 2, "s")]  # e.g., the electric conductivity.
>>> tensor
array([[Q_{xx}, 0, 0],
       [0, Q_{xx}, 0],
       [0, 0, Q_{zz}]], dtype=object)
>>> ex
{Q_{xx}: \mathbb{Q}_{0}^{(1)} - \mathbb{Q}_{u}^{(1)}, Q_{zz}: \mathbb{Q}_{0}^{(1)} + 2*\mathbb{Q}_{u}^{(1)}}
>>> m = Group("MPG:15.6.58")  # 4/mm'm', a ferromagnet along z.
>>> tensor, ex = m.response_tensor_all("T")[("T", 2, "a")]  # e.g., the anomalous Hall effect.
>>> tensor
array([[0, T_{xy}, 0],
       [-T_{xy}, 0, 0],
       [0, 0, 0]], dtype=object)
>>> ex
{T_{xy}: \mathbb{M}_{z}^{(1)}}
>>> m = Group("MPG:20.4.74")  # -3'm', e.g., Cr2O3.
>>> tensor, ex = m.response_tensor_all("M")[("M", 2, "s")]  # magneto-electric effect.
>>> tensor
array([[M_{xx}, 0, 0],
       [0, M_{xx}, 0],
       [0, 0, M_{zz}]], dtype=object)
>>> ex
{M_{xx}: \mathbb{M}_{0}^{(1)} - \mathbb{M}_{u}^{(1)}, M_{zz}: \mathbb{M}_{0}^{(1)} + 2*\mathbb{M}_{u}^{(1)}}
>>> m = Group("MPG:13.2.45")  # 4mm1', a polar crystal (e.g., a Rashba system).
>>> tensor, ex = m.response_tensor_all("G")[("G", 2, "a")]  # Edelstein effect.
>>> tensor
array([[0, G_{xy}, 0],
       [-G_{xy}, 0, 0],
       [0, 0, 0]], dtype=object)
>>> ex
{G_{xy}: \mathbb{Q}_{z}^{(1)}}
>>> m = Group("MPG:18.2.66")  # 321', a chiral crystal (e.g., Te).
>>> tensor, ex = m.response_tensor_all("G")[("G", 2, "s")]  # Edelstein effect.
>>> tensor
array([[G_{xx}, 0, 0],
       [0, G_{xx}, 0],
       [0, 0, G_{zz}]], dtype=object)
>>> ex
{G_{xx}: \mathbb{G}_{0}^{(1)} - \mathbb{G}_{u}^{(1)}, G_{zz}: \mathbb{G}_{0}^{(1)} + 2*\mathbb{G}_{u}^{(1)}}
```

In 4/mmm, the conductivity is $\mathrm{diag}(Q_{xx}, Q_{xx}, Q_{zz})$, given by the active monopole $\mathbb{Q}_0$ and
quadrupole $\mathbb{Q}_u$. In the ferromagnet 4/mm'm', the only nonzero anti-symmetric components are
$T_{xy} = -T_{yx}$, given by the active magnetic dipole $\mathbb{M}_z$, i.e., the magnetization along $z$: the
anomalous Hall effect. In -3'm' (e.g., Cr$_2$O$_3$), the magneto-electric tensor is
$\mathrm{diag}(M_{xx}, M_{xx}, M_{zz})$, given by the active magnetic monopole $\mathbb{M}_0$ and magnetic quadrupole
$\mathbb{M}_u$. The Edelstein effect appears in its anti-symmetric part in the polar 4mm1', given by the active electric
dipole $\mathbb{Q}_z$, and in its symmetric part in the chiral 321', given by the active electric toroidal monopole
$\mathbb{G}_0$ and quadrupole $\mathbb{G}_u$.

(multipolar-harmonics)=
## 8. Multipolar harmonics

A multipolar harmonics combines a point-group harmonics with an internal degree of freedom, e.g., a displacement, an
electric polarization, or a spin at each point.

**Internal degree of freedom.** The internal degree of freedom is fixed by its rank `s` (`s = 1`: a vector;
`s = 2, 3`: higher-rank tensors) and its type `x`: polar (`x = q`, e.g., a displacement or an electric polarization) or
axial (`x = g`, e.g., a spin or a rotation). Its basis $e_\nu$ is the set of the rank-`s` orbitals of that type, of the
cubic family (O$_{\rm h}$) or of the hexagonal family (D$_{\rm 6h}$), written with the symbols $Q_\nu$ (`x = q`) or
$G_\nu$ (`x = g`), e.g., $(Q_x, Q_y, Q_z)$ or $(G_x, G_y, G_z)$ for `s = 1`. The bases are in
`Group.global_info()["harmonics"]["internal_basis"]`, by the family (`"cubic"` or `"hexagonal"`) and `(s, x)`.

**Multipolar spherical harmonics.** The multipolar spherical harmonics of total rank $l$ couple the orbital part of
rank $l + k$ with the internal basis:

$$
O_{lm}^{(s)}(k) = i^{k+s} (-1)^{l+m} \sqrt{2l+1} \sum_{\nu}
\begin{pmatrix} l+k & l & s \\ m-\nu & -m & \nu \end{pmatrix} O_{l+k, m-\nu}\, e_\nu,
\qquad k = -s, \dots, s.
$$

**Type of the multipole.** For a fixed internal type `x`, the type `X` of the multipole is given by the parity of
`s + k`:

| internal type | `s + k` even | `s + k` odd |
|:--|:--|:--|
| `x = q` (polar) | `Q` | `G` |
| `x = g` (axial) | `G` | `Q` |

That is, `X` has the same polar or axial character as the internal basis if `s + k` is even, and the opposite one if
`s + k` is odd. The multipolar harmonics of a point group is $\sum_m U_{m\gamma} O_{lm}^{(s)}(k)$, with $U$ of the
point-group harmonics `(X, l, Gamma, n)`.

**Key and value.** The key is `PGMultipoleType(X, l, Gamma, n, p, s, k, x)` with `s = 1, 2, 3` and `l <= 3`, for all 47
point groups. `Group.multipolar_harmonics` gives, for each key, the coefficients of the internal basis (`dim x` the
number of the internal basis functions, polynomials in $x, y, z$) and the expression in terms of the internal basis
symbols. The symbol has an arrow and the superscript $(s, k)$, and the internal type is written as $[q]$ or $[g]$, e.g.,
$\vec{\mathbb{G}}_{1}^{(1,0)}[q](T_{1g})$; `Group.tag_multipole(key, latex=True, vector=True)` gives the symbol with
the arrow.

```python
>>> coeff, ex = g.multipolar_harmonics[("G", 1, "T1g", -1, -1, 1, 0, "q")]  # Oh.
>>> coeff  # rows: components of T1g, columns: Q_x, Q_y, Q_z.
array([[0, sqrt(2)*z/2, -sqrt(2)*y/2],
       [-sqrt(2)*z/2, 0, sqrt(2)*x/2],
       [sqrt(2)*y/2, -sqrt(2)*x/2, 0]], dtype=object)
>>> ex
array([sqrt(2)*Q_{y}*z/2 - sqrt(2)*Q_{z}*y/2, -sqrt(2)*Q_{x}*z/2 + sqrt(2)*Q_{z}*x/2,
       sqrt(2)*Q_{x}*y/2 - sqrt(2)*Q_{y}*x/2], dtype=object)
```

*Examples (O$_{\rm h}$, `s = 1`).* With the polar vector $\boldsymbol{Q} = (Q_x, Q_y, Q_z)$ (`x = q`) or the axial
vector $\boldsymbol{G} = (G_x, G_y, G_z)$ (`x = g`) as the internal basis:

| key | symbol | expression | meaning |
|:--|:--|:--|:--|
| `("Q", 0, "A1g", -1, -1, 1, 1, "q")` | $\vec{\mathbb{Q}}_{0}^{(1,1)}[q](A_{1g})$ | $(xQ_x + yQ_y + zQ_z)/\sqrt{3}$ | $\boldsymbol{r} \cdot \boldsymbol{Q}$, electric monopole |
| `("Q", 1, "T1u", -1, -1, 1, -1, "q")` | $\vec{\mathbb{Q}}_{1}^{(1,-1)}[q](T_{1u})$ | $(Q_x, Q_y, Q_z)$ | the polar vector itself |
| `("G", 1, "T1g", -1, -1, 1, 0, "q")` | $\vec{\mathbb{G}}_{1}^{(1,0)}[q](T_{1g})$ | $(zQ_y - yQ_z, xQ_z - zQ_x, yQ_x - xQ_y)/\sqrt{2}$ | $\boldsymbol{Q} \times \boldsymbol{r}$, electric toroidal dipole |
| `("G", 0, "A1u", -1, -1, 1, 1, "g")` | $\vec{\mathbb{G}}_{0}^{(1,1)}[g](A_{1u})$ | $(xG_x + yG_y + zG_z)/\sqrt{3}$ | $\boldsymbol{r} \cdot \boldsymbol{G}$, electric toroidal monopole |

For example, an arrangement of electric dipoles $\boldsymbol{Q}(\boldsymbol{r}_i)$ on the sites $\boldsymbol{r}_i$ that
curls around the center, $\boldsymbol{Q} \propto \hat{z} \times \boldsymbol{r}$, is the electric toroidal dipole
$\vec{\mathbb{G}}_{1}^{(1,0)}[q](T_{1g})$ along $z$.
