チュートリアル#

チュートリアルとして、グラフェン の場合に模型を生成する手順を説明します。

  1. examples ディレクトリから graphene_in.py と graphene_ctrl.py をダウンロードします。

  2. 上の二つのファイルがある場所で、次を実行します：

    $ mp_create -v graphene_in.py

    graphene ディレクトリの下に、次のファイルが作られます：

    • graphene.pkl：模型の情報のファイル（バイナリ）

    • graphene.tex、graphene.pdf：模型の情報のまとめ

    • graphene.qtdw：模型の構造の QtDraw ファイル

    .tex/.pdf ファイルは、"pdf": {"create": True}（デフォルト）で、かつインストールに挙げた TeX の構成要素（pLaTeX、ptex2pdf、LaTeX パッケージ）が使えるときだけ作られます：

    • latex が見つからない場合は、どちらのファイルも書き出しません（-v を付けると、その旨を表示します）。

    • そうでなければ、まず .tex ファイルを書き出します。そのあと ptex2pdf や LaTeX パッケージがないとわかった場合や、コンパイルが失敗したり終わらなかったりした場合は、警告を表示し、以前の実行で作られたものや不完全なものである .pdf ファイルを削除します（例えば権限がないなどの理由で削除できない場合を除きます）。

    • .pkl ファイルとほかの出力は、どの場合にも書き出します。

    .qtdw ファイルは、"qtdraw": {"create": True}（デフォルト）で、かつ QtDraw がインストールされているときだけ作られます（-v を付けると、QtDraw が見つからない場合にその旨を表示します）。

  3. 模型を解析する（例えば分散を描く）には、次を実行します：

    $ mp_analyze -v graphene_ctrl.py

    graphene ディレクトリの下に、次のファイルが作られます：

    • info/graphene_matrix.py、info/graphene_hr.dat：選んだ SAMB の行列の完全な情報

    • output/：物理量のさまざまな出力

    • samb/：SAMB の QtDraw ファイル。samb_figure が True で、QtDraw がインストールされていて、模型が "qtdraw": {"create": True} で作られたときに書き出します。samb_figure が True でもほかの条件のどれかが満たされない場合は、警告を表示し、ディレクトリは作りません。

  4. graphene.pkl を対話的に扱うには、IPython のインターフェースを使います。詳しくは analyze_model.ipynb を参照してください。

模型の入力ファイル#

グラフェンの場合、模型の入力ファイルは次のとおりです。

# graphene_in.py
graphene_in = {
    "model": "graphene",  #  name of model.
    "group": 191,  # No. of space group.
    "cell": {"c": 4},  # set large enough interlayer distance.
    #
    "site": {"C": ("[1/3,2/3,0]", "pz")},  # positions of C site and its orbital.
    "bond": [("C", "C", [1, 2])],  # C-C bonds up to 2nd neighbors.
    #
    "spinful": False,  # spinless.
    #
    "SAMB_select": {  # select combined SAMB.
        "X": [],  # all Q/G/M/T.
    },
}

ほかの設定はデフォルト値で与えられ、それは次のとおりです：

# default model input.
default_model = {
    "model": "unknown",
    "group": "C1",  # PG or SG tag (MPG/MSG are not supported).
    "cell": {},
    "spinful": False,
    # acceptable orbital names (tesseral) in site:
    #   s, p=(px, py, pz), d=(dv, dxy, dxz, dyz, du), f=(fc, fs, fbz, f3, fx, fy, faz).
    #   (Ver.3 renamed f2, f1, f3x, f3y to fc, fs, fx, fy.)
    #   (s,u), (s,d), ...
    #   (1/2,s), (1/2,p), (3/2,p), (3/2,d), (5/2,d), (5/2,f), (7/2,f).
    "site": {},
    "bond": [],
    "SAMB_select": {  # select combined SAMB.
        "X": ["Q", "G"],  # type, "Q/G/M/T", []=all.
        "l": [],  # rank, []=all.
        "Gamma": [],  # "IR"=identity, []=all, "..."/["...","..."]=specified irreps.
        "s": [],  # spin, 0/1, []=all.
    },
    "atomic_select": {  # select atomic SAMB.
        "X": [],  # type, "Q/G/M/T", []=all.
        "l": [],  # rank, []=all.
        "Gamma": [],  # "IR"=identity, []=all, "..."/["...","..."]=specified irreps.
        "s": [],  # spin, 0/1, []=all.
    },
    "site_select": {  # select site-cluster SAMB.
        "l": [],  # rank, []=all.
        "Gamma": [],  # "IR"=identity, []=all, "..."/["...","..."]=specified irreps.
    },
    "bond_select": {  # select bond-cluster SAMB.
        "X": [],  # type, "Q/G/M/T", []=all.
        "l": [],  # rank, []=all.
        "Gamma": [],  # "IR"=identity, []=all, "..."/["...","..."]=specified irreps.
    },
    "toroidal_priority": False,
    "qtdraw": {
        "create": True,  # create QtDraw file ?
        "mode": "standard",  # mode, "standard/detail".
        "view": None,  # [a,b,c], if None, default=[6,5,1].
        #
        "rep_site": True,  # show representative site ?
        "rep_bond": True,  # show representative bond ?
        #
        "max_neighbor": 5,  # max. neighbor to draw.
        "cell_mode": None,  # "off/single/all", if None, single for SG, off for PG.
        "scale": None,  # default or magnification scale.
        "site_radius": 0.07,  # base site radius.
        "bond_width": 0.02,  # base bond width.
    },
    "pdf": {
        "create": True,  # create PDF file ?
        "common_samb": True,  # display common SAMB ?
        "harmonics": True,  # display harmonics ?
        "max_neighbor": 5,  # max. neighbor to write (None: all).
    },
}

グラフェンの場合のように、どの設定でも上書きできます。

制御ファイル#

グラフェンの場合、制御ファイルは次のとおりです。

# graphene_ctrl.py
graphene_ctrl = {
    "samb": {
        "model": "graphene",
        "parameter": {
            "z2": 1.0,
        },
        "samb_figure": True,
        "k_multipole": True,
    },
    "output": {
        "dispersion": {
            "k_path": "Γ-M-K-Γ",
            "k_point": {"Γ": "[0,0,0]", "K": "[1/3,1/3,0]", "M": "[1/2,0,0]"},
        },
    },
}

制御ファイルのデフォルト値は次のとおりです：

# default control.
default_control = {
    "mode": "samb",  # samb (SAMB-based only), wannier (wannier-based only), symcw (SAMB and wannier based).
    "grid": (50, 50, 50),  # k-grid size (b1, b2, b3).
    "samb": {
        "model": None,  # model name for .pkl (optional in wannier mode).
        "select": {  # SAMB select condition, where S=site name, R=orbital rank, N=neighbor bond.
            # "site": [("A", [1, 2])],  # S or (S, [R]) in list.
            # "bond": [[0, 1, 2]],  # S1;S2, N, [N], (S1;S2, N), (S1;S2, [N]), (S1;S2, R1;R2), (S1;S2, R1;R2, N) or (S1;S2, R1;R2, [N]) in list.
            # "X": [],  # SAMB type Q/G/T/M in list. empty []=all.
            # "l": [],  # SAMB rank, 0, 1, ..., 11 in list. empty []=all.
            # "Gamma": ["A1g"],  # SAMB irreps. in list. "IR"=identity irrep., empty []=all.
            # "s": [],  # SAMB internal rank, 0,1 in list. empty []=all
        },
        "parameter": {  # SAMB with finite weight (float, or str of sympy const., e.g., "sqrt(2)"), or filename of z_j dict (.py file relative to model_name/info/).
            # "z1": 1.0,
        },
        "samb_figure": False,  # save SAMB QtDraw files ?
        "k_multipole": False,  # compute momentum multipole ?
        "NG_sum_rule": False,  # Nambu-Goldstone sum rule ?
    },
    "wannier": {  # Closest Wannier (CW) or SymWannier setting.
        "dir": "wannier",  # directory for wannier input, i.e., "./seedname/wannier".
        "seedname": None,  # read +(.win, .nnkp, _hr.dat, _wsvec.dat if exists, ...).
        "ket_wannier": [],  # correspondence between Wannier and MultiPie basis, [MultiPie ket name, "orbital@site(sublattice)"] in Wannier order. If empty, automatically determined.
    },
    "output": {  # physical quantity setting.
        "dir": "output",  #  output directory.
        "fourier": {"tb_gauge": True},  # TB gauge ?
        "dos": False,  # DOS: False (none), "auto" (partial DOS for each site cluster and orbital, spin summed), or [[ket name]] (sum of partial DOS of the kets in each list). total DOS is always included.
        "dos_e_num": 1000,  # number of energy points of DOS (range includes all eigenvalues).
        "dos_width": None,  # Gaussian broadening of DOS. if None, 1% of the band width.
        "dos_method": "gaussian",  # DOS method, "gaussian" or "tetrahedron" (optimized tetrahedron method by libtetrabz).
        "dos_spin": False,  # resolve spin, u/d, of spinful basis in "auto" DOS ?
        "n_electron": None,  # number of occupied states per primitive cell (one per band) to determine fermi energy. if None, 0 (samb mode) or that of seedname.win.
        "save_k_path": False,  # save Ek, Uk along k path in .npz ?
        "save_k_full": False,  # save Ek, Uk on full k grid in .npz ?
        "callback_k_path": None,  # file (.py, relative to topdir) defining callback_k_path(Ek, Uk, info), called with eigen system along k path.
        "callback_k_full": None,  # file (.py, relative to topdir) defining callback_k_full(Ek, Uk, info), called with eigen system on full k grid.
        "callback_info": [],  # quantities added to info of callback_k_full as info[keyword], [k,n] on full k grid. local quantity, "Sx/Sy/Sz/Lx/Ly/Lz/Qu/Qv/Qyz/Qxz/Qxy", or SAMB, "zj".
        "dispersion": {  # dispersion info.
            "power": None,  # positive power p: Ek^p is used in the dispersion and DOS, with fermi energy = 0 (n_electron cannot be used). -|Ek|^p if Ek^p is not a real number (negative Ek with non-integer p). if None, power=1.
            "k_path": "",  # symmetry line, separated by "-". disconnected points by "|". if empty str, default values are used for k_path and k_point.
            "k_point": {"Γ": "[0,0,0]"},  # k-point (fractional, primitive cell of model, or of seedname.win without model).
            "local": [],  # local quantity, "Sx/Sy/Sz/Lx/Ly/Lz/Qu/Qv/Qyz/Qxz/Qxy".
            "weight": False,  # orbital weight (fat band): False (none), "auto" (each site cluster and orbital, spin summed), or [[ket name]].
            "z": [],  # SAMB, [zj], expectation value <u_kn|Z_j(k)|u_kn> of each band along k path.
        },
        "z_expectation": [],  # SAMB, [zj] or "all" (all selected SAMBs), expectation value summed over occupied states (T=0) per primitive cell.
    },
}

典型的な使い方では、まずすべての既約表現の SAMB を作り、それから制御ファイルで samb/select や samb/parameter を指定して、恒等表現に加えて対称性を破る項などの必要な SAMB を選びます。

後処理ツール#

状態密度、フィリングからのフェルミエネルギー、軌道の重み（ファットバンド）、固有値と固有ベクトルの出力、独自の計算のためのコールバック、局所演算子、SAMB の期待値は、制御ファイルの output で設定します。詳しい説明と例は後処理ツールを参照してください。

入力ファイルの形式#

模型の入力ファイルと制御ファイルは、辞書を含む Python ファイルです（例：graphene_in = {...}）。

  • これらは Python のコードとしては実行されません。各辞書は ast.literal_eval で読むので、リテラル（文字列、数値、リスト、タプル、辞書、True/False/None）だけが使えます。2*2 のような算術、変数、import は使えません。

  • 分数や記号的な値は、文字列で与えます（例："[1/3,2/3,0]"）。数式を表す文字列は SymPy で解析します。

  • mp_create（または create_model）では、模型の入力ファイル中のすべての辞書 name = {...} をそれぞれ別の模型として扱い、mp_analyze（または analyze_model）では、制御ファイル中のすべての辞書をそれぞれ別の制御として扱います。MaterialModel.analyze(filename) と ModelAnalyzer.analyze(filename) は、1 つのファイルに 1 つの辞書を想定しています。

  • 未知のキー（例えば "spinfull" のようなタイプミス）はエラーになります：ValueError: unknown key(s) in model 'x': 'spinfull' (did you mean 'spinful'?). 受け付けるキーは、上のデフォルトの模型とデフォルトの制御にあるキーと、次のものです。

    • cell：a、b、c、alpha、beta、gamma

    • SAMB_select、atomic_select、site_select、bond_select：X、l、Gamma、s

    • samb/select：site、bond、X、l、Gamma、s

    次の辞書のキーはデフォルトと照合しませんが、それぞれの規則があります：

    • site のサイト名：; を含まない空でない文字列で、bond で使うサイトでは _ も含まないもの（; と _ はサイトとボンドのクラスターの名前に使います）。名前は PDF（LaTeX）やファイル名にも現れるので、すべてのサイトで英数字（例："Fe1"）を推奨します。模型名とサイト名に含まれる LaTeX の特殊文字（例：# や %）は、PDF ではエスケープされます。

    • samb/parameter の SAMB 名：生成した SAMB の名前（例："z1"）。samb/parameter には、同じ形の辞書を 1 つ含む Python ファイルの名前を与えることもできます。そのときは model_name/info/ からの相対パスで、拡張子を付けて与えます（例：model_name/info/my_z.py なら "my_z.py"。"info/my_z.py"、"my_z"、絶対パスではありません）。パラメータが空でないとき、mp_analyze はそれを model_name/info/model_name_z.py に書き出します。このファイルは実行のたびに上書きされるので、編集する場合は別の名前にコピーしてください。

    • output/dispersion/k_point の k 点のラベル：k_path で使うラベルで、-、|、空白を含まないもの（これらは k_path で点を区切るのに使います）。

  • wannier/read_KS は削除しました："read_KS": True はエラーになり、古い制御ファイルにある "read_KS": False は警告を出して無視します（制御ファイルから削除してください）。

Note

入力ファイル中の数式を表す文字列は、SymPy の parse_expr で解析します。これは内部で eval を使います。また、模型のファイル model_name.pkl は Python の pickle で保存しています。 入力ファイルと .pkl ファイルは、信頼できる入手元のものだけを使ってください。

コマンドラインツール#

  • mp_create、mp_analyze、mp_convert は、エラーが起きると終了ステータス 1 で、使い方の誤り（例えば入力ファイルがない、未知のオプション）では終了ステータス 2 で終了します。エラーは、入力ファイルと、該当する場合は模型とサイトとともに、1 つのメッセージで表示します。-v を付けると、代わりに完全なトレースバックを表示します。

  • 複数の入力ファイルを与えた場合は、どの模型を作成・解析するよりも前に、すべてのファイルを読み込みます。

  • mp_create -i と mp_analyze -i は、デフォルトの模型と制御を表示します。これは入力ファイルのテンプレートとして使えます。

  • python -m multipie.scripts.mp_create、python -m multipie.scripts.mp_analyze、python -m multipie.scripts.mp_convert も同じように動きます。

  • mp_convert は、Ver.2 の模型（.pkl）を Ver.3 に変換し、または 3.2.0 より前の Ver.3 の模型の番号を付け替え、その制御ファイルの重みも変換します（Ver.2 からの変更点を参照）。

  • 経過時間や警告などのメッセージは、multipie ロガーを通して標準出力に書き出します。create_model と analyze_model（したがって mp_create と mp_analyze）は、このロガーにまだハンドラがなければ設定します。アプリケーションのログの設定（例えば Jupyter のルートロガー）は変更しません。メッセージを別の場所に集めるには、これらを呼ぶ前に multipie ロガーにハンドラを加えてください。

並列計算#

原子多極子の行列（multipie.util.util_atomic_multipole の create_atomic_multipole_matrix）と原子 SAMB（Group.create_atomic_samb_L）は、joblib で並列に計算します。 これらはデータベースの生成に使います。 mp_create（MaterialModel.analyze）では、大きな模型（例えば d 軌道を持つスピンありの模型）について、原子 SAMB と結合 SAMB の直交化も並列に行います。小さな模型は逐次に処理します。プロセスの起動のほうが計算より時間がかかるためです。 出力はプロセス数によりません。 プロセス数は環境変数 MULTIPIE_N_JOBS で与えます：

  • 設定なし、または空：すべてのコア（-1、デフォルト）

  • 1：逐次

  • n > 1：n プロセス、n < 0：コア数 + 1 + n プロセス（最低 1）。joblib と同じです。

  • 0 や整数でない値はエラーです。

$ MULTIPIE_N_JOBS=4 python my_script.py   # a script calling the functions above

Windows の PowerShell では、スクリプトを実行する前に $env:MULTIPIE_N_JOBS = "4" とします。この設定は、Remove-Item env:MULTIPIE_N_JOBS で削除するまでセッションの間残ります。

出力ファイル#

出力ファイルの説明は次のとおりです（先頭に model_name が付きます）：

  • model_name：すべてのファイルは model_name の下に作られます。

    • .pdf：模型の情報（PDF）。

    • .pkl：模型のデータ（バイナリ）。

    • .qtdw：模型の構造（QtDraw）。

    • .tex：模型の情報のソース。

    • samb/

      • _atomic_samb.qtdw：原子 SAMB。

      • _A-B-…_def.qtdw：サイトのクラスターの定義（すべてのサイトを 1 つのファイルに）。

      • _A-B-…qtdw：サイトのクラスター SAMB（すべてのサイトを 1 つのファイルに）。

      • _A;B_nnn_m_def.qtdw：A;B（nnn 近接、m）のボンドのクラスターの定義（nnn：近接の次数、3 桁。例：001）。

      • _A;B_nnn_m.qtdw：A;B（nnn 近接、m）のボンドのクラスター SAMB。

    • info/

      • _hr.dat：H[R] の行列データ。

      • _info_output.py：出力の情報。

      • _info_samb.py：模型と SAMB の情報。

      • _info_wannier.py：wannier の情報。

      • _info.py：全体の情報。

      • _k.py：運動量表示の SAMB。

      • _matrix.py：SAMB の行列データ。

      • _var.py：zj と、ボンド 1 での原子のパラメータとの関係（下を参照）。

      • _z.py：zj パラメータ。

    • output/

      • _dispersion.eps：分散（EPS）。

      • _dispersion.pdf：分散（PDF）。

      • _dispersion.txt：分散のデータ。

      • _dos.eps：DOS（EPS）。

      • _dos.pdf：DOS（PDF）。

      • _dos.txt：DOS のデータ（output/dos が False でないとき）。

      • _eigen_k_path.npz、_eigen_k_full.npz：固有値と固有ベクトル（output/save_k_path または output/save_k_full が True のとき）。

      • _weight.pdf：軌道の重みで色付けした分散。

      • _weight.txt：軌道の重み付きの分散（output/dispersion/weight が False でないとき）。

      • plot_dos.gnu、plot_weight.gnu：DOS と軌道の重みを gnuplot で描くためのコマンドスクリプト。

      • plot_band.gnu：gnuplot で描くためのコマンドスクリプト。

_var.py は、各ボンドクラスターについて、そのボンド 1 の head と tail のサイトと、恒等表現の各 \(z_j\) をボンド 1 の行列要素で表した式を与えます（3.2.0 から）。例えばグラフェンでは：

graphene_var = {
    "C;C_001_1": {"bond": ("C(2)", "C(1)"), "z2": "sqrt(6)*g_{pz,pz}"},
    "C;C_002_1": {"bond": ("C(1)", "C(1)"), "z3": "2*sqrt(3)*g_{pz,pz}"},
}

  • "bond"：ボンド 1 の（head のサイト, tail のサイト）で、原子(副格子) の形です。

  • g_{a,b} と h_{a,b}：ボンド 1 の、head の軌道 a と tail の軌道 b の間の行列要素は \(H_{a,b} = g_{a,b} + i h_{a,b}\) です。

  • 軌道は、スピンのない模型ではそのまま（例えば pz）、スピンのある模型（lgs）では (px,u) と (px,d) を pxu と pxd と書きます。jml 基底ではランクの文字を付け、例えば p の (3/2,1/2) を p(3/2,1/2) と書きます。同じ \((j, m)\) の p と d を区別するためです。
